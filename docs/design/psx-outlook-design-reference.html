Notes for implementation

  • Inspect the platform's existing design tokens/component library first. If tokens for surface, border, text-secondary, danger, warning, success already exist, map onto those instead of the hex values here.
  • Keep interactions smooth: 150ms for hover/toggle state changes, 300ms ease for bar width/height and range position changes. Nothing should snap instantly.
  • Confidence chip thresholds used here: 100+ independent periods = strong evidence, 30–99 = moderate, under 30 = limited. Adjust thresholds if the actual data availability differs.
  • Detailed/technical numbers (raw sample sizes, percentile tables, data-source gaps) belong behind a "show details" toggle or a separate advanced view, not in the default beginner view.
  • Replace the font stack with the platform's actual brand font.
  • This file is a static reference, not a component to paste in directly — rebuild these patterns in the app's actual framework and component system.
